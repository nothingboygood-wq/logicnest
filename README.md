# LogicNest Website (Multi-page)

Clean black-and-white multi-page website for LogicNest.

## Pages
- `/` home
- `/about.html` about
- `/services.html` services
- `/hire.html` hire form + ticket submission
- `/admin/` hidden admin dashboard (not linked in public nav)

## Config (env-style)
Set runtime values in `config.js` (or generate it during deploy):
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `ADMIN_PASSWORD`

Use `config.example.js` as template.

## Run locally
```bash
python3 -m http.server 4173
```
Open `http://localhost:4173` and `http://localhost:4173/admin/`.

## Supabase SQL
```sql
create table if not exists public.tickets (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  budget text not null,
  message text not null,
  source text default 'website',
  created_at timestamptz default now()
);
```
